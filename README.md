# Week 2 - Firmware Development and Implementation

## Project
ESP32-Based Smart Home Environment Monitoring and Safety System

## Objective
The objective of this project is to develop firmware for an ESP32-based
embedded system that monitors environmental conditions and provides
safety alerts.

## Wokwi Simulation

![Wokwi Simulation](screenshots/Capture.png)
## Hardware
- ESP32
- DHT22
- PIR Sensor
- LDR
- Gas Sensor
- LED
- Buzzer

## Software
- Arduino IDE
- Wokwi Simulator
- Embedded C/C++

## Features
- Temperature monitoring
- Humidity monitoring
- Motion detection
- Light-level monitoring
- Gas-level monitoring
- LED and buzzer safety alerts
- UART/Serial Monitor debugging
- Periodic sensor monitoring

## Simulation
The firmware can be simulated using Wokwi.

## Testing
The system was tested under normal conditions, high-temperature
conditions, high gas-level conditions, and motion detection conditions.
